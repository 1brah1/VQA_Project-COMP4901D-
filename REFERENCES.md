# References

Primary papers, model cards, and tooling references used in this project:

## Vision Encoder
- SigLIP paper: Zhai et al., "Sigmoid Loss for Language Image Pre-training" (2023). https://arxiv.org/abs/2303.15343
- SigLIP model card: https://huggingface.co/google/siglip-base-patch16-384

## Language Model
- Qwen2.5 model card (training and inference): https://huggingface.co/Qwen/Qwen2.5-1.5B-Instruct
- Qwen technical report: https://arxiv.org/abs/2309.16609

## Parameter-Efficient Fine-Tuning
- LoRA paper: Hu et al., "LoRA: Low-Rank Adaptation of Large Language Models" (2021). https://arxiv.org/abs/2106.09685
- PEFT library: https://github.com/huggingface/peft

## Quantization
- AWQ paper: Lin et al., "AWQ: Activation-aware Weight Quantization for LLM Compression and Acceleration" (2023). https://arxiv.org/abs/2306.00978
- AutoAWQ repository: https://github.com/casper-hansen/AutoAWQ

## Speculative Decoding
- Speculative decoding: Leviathan et al., "Fast Inference from Transformers via Speculative Decoding" (2023). https://arxiv.org/abs/2302.01318
- Self-speculative decoding overview: https://arxiv.org/abs/2305.10427

## TTS
- Piper TTS: https://github.com/rhasspy/piper
- Silero TTS: https://github.com/snakers4/silero-models
- VibeVoice model card (streaming reference): https://huggingface.co/microsoft/VibeVoice-Realtime-0.5B
